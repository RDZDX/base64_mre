# Base64_mre
App demonstrate how to encode/decode data to base64.
For using with Nokia mobile phone, app must be signed with IMSI (your SIM card) code.
https://vxpatch.luxferre.top/
Application files - "[Bin2b64U.vxp](https://rdzdx.github.io/base64_mre/Bin2b64U.vxp)", "[Bin2b64.vxp](https://rdzdx.github.io/base64_mre/Bin2b64.vxp)", "[B642bin.vxp](https://rdzdx.github.io/base64_mre/B642bin.vxp)".
